# 学习路线规划

> 目标：系统掌握机器学习与深度学习，产出可发表的研究成果与开源项目。
> 起点：软件工程本科在读，线性代数已修，概率论在修；Python 起步阶段。

---

## 一、先认清现实：一学期不能什么都做

手上同时有：**六级 + 外研社国才杯 + 全国大学生数学竞赛 + AI 学习 + 专业课**。

五件事同时全力推，结果一定是五件都做不好。所以必须有取舍。

### 本学期节奏

| 时间段 | 主战场 | AI 投入 | 说明 |
|---|---|---|---|
| 9月 - 11月底 | **竞赛** | 每周 3-5 小时 | AI 只做「最低维持量」 |
| 12月 | **六级 + 期末** | 每周 2-3 小时 | 考试优先 |
| 1月 - 2月（寒假） | **AI 全力输出** | 每周 20+ 小时 | 黄金期 |
| 3月 - 6月 | **项目 + 进实验室** | 每周 10-15 小时 | 争取可投稿成果 |

**核心逻辑**：9-11 月不要贪。把 AI 当「背景任务」，能做多少做多少。真正发力在寒假。

## 二、为什么先做项目，而不是先想论文

一上来就冲「我要发论文」，通常卡在这几个地方：

| 难点 | 具体情况 |
|---|---|
| 没有数据 | 想做的东西找不到公开数据集 |
| 没有算力 | 想复现大模型，消费级显卡跑不动 |
| 没有 baseline | 做出的东西无法证明「比现有方法好」 |
| 想法已被做过 | 查文献发现几年前就有人发了 |
| 没有人带 | 不知道什么问题值得做，结果合不合理 |

**而先做 GitHub 项目能解决其中大部分问题**：

- 项目是实验平台——论文里的实验都在这个平台上跑
- 项目做好了，**导师会主动找你**，比空口说「想发论文」有效得多
- 项目本身是简历上的硬通货，找实习时比绩点管用

**结论：项目是地基，论文是房子。先打地基。**

## 三、技术路线

### 阶段 1 · Python 与数据工具 ✅

- [x] numpy 数组与向量化运算
- [x] pandas 数据加载与清洗
- [x] matplotlib 可视化
- [ ] 把这套工具用在一个「自己的数据集」上

**检验标准**：能独立完成「读 CSV → 清洗 → 统计分析 → 出 3 张图」的完整流程。

---

### 阶段 2 · 经典机器学习 ⬜ 进行中

目标不是背算法，而是建立**「用数据解决预测问题」的完整思维**。

| 主题 | 必须掌握的 |
|---|---|
| 数据预处理 | 缺失值、异常值、标准化、类别编码 |
| 监督学习 | 线性回归、逻辑回归、决策树、随机森林、SVM |
| 无监督学习 | KMeans 聚类、PCA 降维 |
| 模型评估 | 交叉验证、混淆矩阵、精确率/召回率/F1、ROC-AUC |
| 超参数调优 | GridSearchCV、RandomizedSearchCV |

**做完这一阶段，就有能力做出第一个像样的项目了。**

---

### 阶段 3 · 深度学习 ⬜ 寒假主攻

- [ ] PyTorch 张量与自动求导
- [ ] 神经网络从零搭（手写 MLP）
- [ ] CNN（图像任务）
- [ ] RNN/LSTM 或 Transformer（序列任务）
- [ ] 迁移学习（预训练模型微调）

**算力说明**：8GB 显存（RTX 4060/4070 Laptop）够用。
模型参数量控制在 1 亿以内可自由训练；7B 级别模型只能做 LoRA 微调。

---

### 阶段 4 · 找自己的方向 ⬜

到这一步才能谈选题。适合起步、算力要求低、有 baseline 的方向：

| 方向 | 数据来源 | 优势 |
|---|---|---|
| 表格数据 / 时序预测 | Kaggle、UCI | 消费级显卡够用，效果可量化 |
| 文本分类 / 情感分析 | 公开中文语料 | 预训练模型微调即可起步 |
| 图像小任务（缺陷检测、分类） | 公开数据集 | 可视性强，论文好写 |
| 多模态小任务 | 图文配对数据 | 相对新，容易找切入点 |

## 四、每周 15 小时怎么分配（竞赛结束后）

| 内容 | 时间 | 说明 |
|---|---|---|
| 看教程 / 读书 | 3 h | 输入 |
| 写代码练习 | 6 h | 主力，必须自己动手 |
| 读论文 / 查资料 | 3 h | 每周精读 1 篇 |
| 整理笔记 / 写文档 | 2 h | 沉淀，也是写作训练 |
| 复盘与规划 | 1 h | 每周日晚上做 |

**关键原则：写代码的时间必须超过看教程的时间。** 只输入不输出，等于没学。

## 五、关于联系导师

**进实验室、有人带，比自学许久都值。** 第一次见面聊什么，决定了在对方心里的定位。

### 见面之前

1. 查对方研究方向，读近 2-3 年的论文
2. 准备一个**具体问题**，例如「您某篇用了 X 方法，如果换成 Y 会怎样」
3. 想清楚想得到什么：进实验室？指导方向？还是只是聊聊

### 该说的

- 坦诚说明水平：**「Python 刚开始学，线代学过，概率论在学」**
- 明确态度：**「我想长期做，愿意从数据清洗、跑实验这些基础活做起」**
- **别装。** 装出来的水平，第一次任务就露馅

### 不该说的

- ❌「我想发论文」——显得浮躁
- ❌「AI 怎么入门」——这种问题自己搜就有答案
- ❌ 承诺做不到的投入时间

### 如果对方要派活

**接。** 无论是打标数据、复现论文、跑实验——这是最便宜的入场券。

---

## 六、三条铁律

1. **报错是最好的老师。** 完整读一遍错误信息，90% 的答案就在里面。
2. **改了参数再看结果。** 跟着抄代码学不会，必须自己折腾。
3. **每个成果都写进仓库。** 哪怕 20 行的小脚本，也是积累。
